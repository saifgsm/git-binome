# Git en binôme

**Binôme : Sifeddine Gouasmia & Roland Dansou**

## Description

Exercice pour apprendre à travailler à deux sur un même dépôt Git : chaque membre travaille sur sa propre branche, puis l'intègre à `main` par une pull request.

## Sujet du projet

Notre projet sera un **site de recettes**.

## Contenu du dépôt

- `personne-a.md` : présentation et objectifs de Sifeddine.
- `personne-b.md` : présentation et compétences de Roland.

## Ce que nous avons pratiqué

- Création de branches (`presentation-a`, `presentation-b`).
- Commits et push vers GitHub.
- Ouverture et merge de pull requests.
